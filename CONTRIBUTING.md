## 🎯 How to Contribute

### 1. **Report Bugs**
- Check if issue already exists
- Use bug report template
- Include steps to reproduce
- Include environment details

### 2. **Suggest Features**
- Check if feature already requested
- Describe use case clearly
- Include examples

### 3. **Improve Documentation**
- Fix typos
- Add examples
- Translate to Amharic/Oromo
- Add screenshots

### 4. **Write Code**
- Fix bugs
- Add features
- Improve performance
- Add tests

### 5. **Help Farmers**
- Share the app
- Provide feedback
- Translate messages
- Train others
