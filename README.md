## 🌱 **Overview**

Ethio-Agri Advisor is a **free, AI-powered** agricultural advisory system designed specifically for **Ethiopian farmers**. It provides personalized crop recommendations, disease detection, yield predictions, and community support - all accessible via **web** and **Telegram**!

### 🎯 **Why This Matters**

- **70%** of Ethiopians depend on agriculture
- **40%** of crops lost to pests and diseases
- **30%** yield increase possible with better advice
- **10M+** smallholder farmers need support

### ✨ **Key Features**

| Feature | Description | Access |
|---------|-------------|--------|
| 🌾 **Crop Advice** | Personalized planting, fertilizer, harvest guidance | Web + Telegram |
| 🐛 **Disease Detection** | Identify pests and diseases from symptoms/photos | Web + Telegram |
| 📊 **Yield Calculator** | Estimate harvest and expected income | Web + Telegram |
| 👥 **Community Forum** | Share tips and learn from other farmers | Web + Telegram |
| 🌤️ **Weather Updates** | Real-time forecasts and alerts | Telegram |
| 💰 **Market Prices** | Current crop prices in Ethiopia | Telegram |
| 🗣️ **Bilingual** | Full Amharic and English support | All |
